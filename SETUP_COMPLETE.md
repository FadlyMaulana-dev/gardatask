## 🚀 Quick Start (5 Minutes)

### Backend
```bash
cd backend
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate
php artisan serve
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```

✅ Ready at:
- Backend: http://localhost:8000
- Frontend: http://localhost:5173
